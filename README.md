# Monique's Helper

A small phone app for bills, fortnightly pay, budget and loan repayments.

- **Bills**: add and edit bills, line them up with your fortnightly payday, mark them paid (paid bills stay in that fortnight with ✓ Paid and the date).
- **Budget**: one budget per pay fortnight. Type each fortnight's wages (they can change), and bills and loan repayments due in that fortnight are added at their real amounts. Add other spending too.
- **Loans**: money borrowed, payments made, and a repayment plan that shows in Bills and Budget. A mortgage can be added as a repeating bill.
- **Backup**: save a backup file and restore it later.

Everything is saved on the phone only (browser storage). Nothing is sent anywhere.
Open https://phoneapp12-cell.github.io/moniques-helper/ and use "Add to Home Screen" to install it.
